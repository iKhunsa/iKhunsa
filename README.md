### 👋 Sobre mí

- ⚡ Construyo herramientas alrededor de **Bitcoin & Lightning Network**
- 🧾 Co-creo **ZatoBox** — POS modular open-source para PyMEs (BTC, Lightning y pagos locales)
- 🤖 Automatización, OCR y backend con **Alcolabs Agency**
- 📊 Mantengo **Satoshi Dashboard**, app de métricas Bitcoin en el Umbrel App Store
- 🌱 Contribuyo en abierto — Pull Shark, Quickdraw, Pair Extraordinaire, YOLO en GitHub
